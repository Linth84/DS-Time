## About DS-Time

Coordinating people across different time zones shouldn't require doing timezone math.

**DS-Time** generates native Discord timestamps that automatically adapt to the local timezone of whoever reads them.

Choose a date and time, select a format, copy the timestamp, and paste it directly into Discord.

```text
<t:1787590800:F>
